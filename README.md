## Über dieses Projekt

Dieses Repo dient als Übungsfläche, um den Pull-Request-Workflow kennenzulernen:

## Mitwirken

1. Neuen Branch von `main` erstellen
2. Änderung vornehmen und committen
3. Branch pushen und einen Pull Request öffnen
